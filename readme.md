## About
Quickly multi-select to copy and download icons. Port of the material icons library. 

## Features: 
+ keyboard shortcuts and navigation 
  - Flow: `/` activates search, typing filters icons, `tab` + `space` selects icons 
  - `c` copies, `d` downloads. 
  - Lazy loading, with scroll to top btn
  - Shift + select for multi-icon selection

+ Multi-search, 
  - Selection traverses searches so you can have multiple searches, and select things. 
  - Use commas to separate search for multiple icons, for example `child_hat, king_bed, airport_shuttle, account_circle` will give you those icons
